# 拾间

应用显示名称为「拾间」。图标采用用户在 2026-11-16 选定并上传的木质屋形托盘图片，原始图片保存为 `selected-icon.png`。后续品牌调整以这张选图为准。

应用 ID 为 `com.example.tidyspace.pc5853b2a`。显示名称在 `app/src/main/res/values/strings.xml` 中配置，主图标为 `mipmap/ic_spatial_launcher`。

图标资源保持原图宽高比，用原图背景色补足方形。Android 自适应图标另提供安全区前景和单色符号。PICO 桌面图标沿用现有圆形徽标轮廓与相应 SDF，两层贴图更新为所选图片及其背景，保持几何和 SDF 对应。
